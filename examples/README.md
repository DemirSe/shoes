# Örneklerin kapsamı

Bu dizindeki dosyaların çoğu upstream/legacy örneklerdir; güncel fork için
destek veya üretim profiline uygunluk garantisi değildir. Bazıları kaldırılmış
ya da desteklenmeyen protokollere (VMess, Hysteria2 vb.) atıf yapar.
Tarihsel örnekler silinmeden korunur; bu protokoller yeniden etkinleştirilmez.

Güncel yapılandırma için [CONFIG.md](../CONFIG.md) ve
[üretim profili özeti](../docs/konfigurasyon.md) esas alınmalıdır.
